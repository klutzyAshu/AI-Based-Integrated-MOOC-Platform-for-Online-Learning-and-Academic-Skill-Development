    # System Architecture
    
    ## Overview
    
    The platform is a modular, four-layer system: a React frontend, a
    Spring Boot REST backend, a pluggable AI services layer, and a
    MariaDB (MySQL-compatible) database. Each layer is independently deployable.
    
    ```
    ┌──────────────┐     REST/JSON     ┌──────────────┐     JDBC     ┌──────────────┐
    │   Frontend   │ ───────────────▶ │   Backend     │ ───────────▶ │   Database   │
    │  React (Vite)│ ◀─────────────── │  Spring Boot  │ ◀─────────── │   MariaDB    │
    └──────────────┘                  └──────┬───────┘               └──────────────┘
                                              │
                                              │ HTTP / in-process call
                                              ▼
                                       ┌──────────────┐
                                       │  AI Services │
                                       │ chatbot, reco,│
                                       │ assessment,   │
                                       │ personalization│
                                       └──────────────┘
    ```
    
    ## Layers
    
    ### 1. Frontend (React + Vite)
    - Role-aware routing (`ProtectedRoute`) for Student / Instructor / Admin views.
    - `AuthContext` holds the logged-in user and JWT; `services/api.js`
      attaches the token to every request via an Axios interceptor.
    - Pages are grouped by role under `src/pages/{auth,student,instructor,admin}`.
    
    ### 2. Backend (Spring Boot / Java)
    - **Controller** layer: thin REST endpoints (`/api/...`), validation, and
      `@PreAuthorize` role checks.
    - **Service** layer: business logic (enrollment rules, quiz grading,
      AI request routing).
    - **Repository** layer: Spring Data JPA interfaces over the entities.
    - **Security**: `JwtAuthenticationFilter` reads the `Authorization`
      header on every request; `SecurityConfig` wires role-based access
      rules (`/api/admin/**` → ADMIN, `/api/instructor/**` → INSTRUCTOR/ADMIN).
    
    ### 3. AI Services
    - Exposed to the frontend through one endpoint: `POST /api/ai/ask`,
      with a `type` field routing to chatbot / recommendation / assessment
      / personalization behavior inside `AIService`.
    - `AIService` calls a configured LLM provider (OpenAI-compatible chat
      completions API) and degrades gracefully to a placeholder response
      when no API key is set, so the rest of the app still works in dev.
    - Equivalent standalone Python scripts live under `ai/` for local
      experimentation or a future microservice split
      (`ai/chatbot/chatbot.py`, `ai/recommendation/recommend.py`,
      `ai/assessment/generate_quiz.py`, `ai/personalization/study_plan.py`).
    
    ### 4. Database (MariaDB)
    - Schema is split by concern under `database/schema/`
      (`users.sql`, `courses.sql`, `enrollments.sql`, `quizzes.sql`, `ai.sql`).
    - `database/database.sql` creates the database and loads each schema
      file in the correct dependency order.
    - `database/seed/sample_data.sql` provides demo users, a course, and
      lessons for local development.
    
    ## Request Flow Example: Asking the AI Assistant a Question
    
    1. Student types a question on the course page (`CourseView.jsx`).
    2. Frontend calls `POST /api/ai/ask` with `{ type: "CHATBOT", prompt, contextJson }`.
    3. `JwtAuthenticationFilter` validates the token and sets the security context.
    4. `AIController` delegates to `AIService.handle(...)`.
    5. `AIService` calls the configured LLM provider with a system prompt
       plus the student's question and course context.
    6. The reply is returned as JSON and rendered in the chat panel.
    
    ## Key Design Decisions
    
    - **Stateless auth (JWT)** so the backend can scale horizontally.
    - **DTOs at the API boundary** keep JPA entities from leaking
      persistence details into the REST contract.
    - **AI layer isolated behind one controller/service** so the provider
      (or a self-hosted model) can be swapped without touching frontend code.
    - **Role-based route protection** on both the frontend (`ProtectedRoute`)
      and backend (`@PreAuthorize`) for defense in depth.

    ## AI Assistant
    
    ### POST /ai/ask
    Authenticated. Single entry point for all AI features.
    
    ```json
    {
      "type": "CHATBOT",        // CHATBOT | RECOMMENDATION | ASSESSMENT | PERSONALIZATION
      "prompt": "Explain recursion with an example",
      "contextJson": "{\"courseId\": 1}"
    }
    ```
    
    Response:
    ```json
    { "type": "CHATBOT", "reply": "Recursion is when a function calls itself...", "dataJson": null }
    ```
    
    For `ASSESSMENT`, the reply comes back in `dataJson` as a JSON array of
    generated questions matching the `QuizRequest.QuestionItem` shape.

    /**
     * Dispatches requests to the AI layer (chatbot / recommendation /
     * assessment / personalization). Delegates the actual model call to
     * the configured provider; falls back to a canned response if no
     * API key is configured, so the rest of the app still runs in dev.
     */
    @Service
    @RequiredArgsConstructor
    public class AIService {
    
        private final AIConfig aiConfig;
        private final RestTemplate aiRestTemplate;
    
        public AIResponse handle(AIRequest request) {
            return switch (request.getType().toUpperCase()) {
                case "CHATBOT" -> chatbot(request);
                case "RECOMMENDATION" -> recommendation(request);
                case "ASSESSMENT" -> assessment(request);
                case "PERSONALIZATION" -> personalization(request);
                default -> throw new IllegalArgumentException("Unknown AI request type: " + request.getType());
            };
        }
    
        private AIResponse chatbot(AIRequest request) {
            String reply = callModel(
                    "You are a helpful academic assistant for an online learning platform. "
                            + "Answer clearly and concisely, and relate the answer back to the course "
                            + "context when one is given.",
                    request.getPrompt(), request.getContextJson());
            return AIResponse.builder().type("CHATBOT").reply(reply).build();
        }
    
        private AIResponse recommendation(AIRequest request) {
            String reply = callModel(
                    "You recommend the next best course or lesson for a learner based on their "
                            + "goals, current progress, and interests. Return a short, ranked list.",
                    request.getPrompt(), request.getContextJson());
            return AIResponse.builder().type("RECOMMENDATION").reply(reply).build();
        }
    
        private AIResponse assessment(AIRequest request) {
            String reply = callModel(
                    "You generate multiple-choice quiz questions from lesson content. "
                            + "Return valid JSON: a list of {text, options[4], correctIndex, explanation}.",
                    request.getPrompt(), request.getContextJson());
            return AIResponse.builder().type("ASSESSMENT").dataJson(reply).build();
        }
    
        private AIResponse personalization(AIRequest request) {
            String reply = callModel(
                    "You build an adaptive study plan for a learner based on their pace, "
                            + "quiz performance, and available time per week.",
                    request.getPrompt(), request.getContextJson());
            return AIResponse.builder().type("PERSONALIZATION").reply(reply).build();
        }
    
        /**
         * Calls the configured LLM provider's chat-completions endpoint.
         * Returns a graceful placeholder when no API key is set, so local
         * development and tests don't require live credentials.
         */
        private String callModel(String systemPrompt, String userPrompt, String contextJson) {
            if (aiConfig.getApiKey() == null || aiConfig.getApiKey().isBlank()) {
                return "[AI layer not configured] Set app.ai.api-key to enable live responses. "
                        + "Prompt received: " + userPrompt;
            }
    
            try {
                HttpHeaders headers = new HttpHeaders();
                headers.setContentType(MediaType.APPLICATION_JSON);
                headers.setBearerAuth(aiConfig.getApiKey());
    
                String fullPrompt = contextJson != null
                        ? userPrompt + "\n\nContext: " + contextJson
                        : userPrompt;
    
                Map<String, Object> body = Map.of(
                        "model", aiConfig.getModel(),
                        "messages", new Object[]{
                                Map.of("role", "system", "content", systemPrompt),
                                Map.of("role", "user", "content", fullPrompt)
                        }
                );
    
                HttpEntity<Map<String, Object>> entity = new HttpEntity<>(body, headers);
                Map<?, ?> response = aiRestTemplate.postForObject(
                        aiConfig.getBaseUrl() + "/chat/completions", entity, Map.class);
    
                if (response == null) return "AI provider returned no response.";
                return extractReply(response);
            } catch (Exception ex) {
                return "AI request failed: " + ex.getMessage();
            }
        }
    
        @SuppressWarnings("unchecked")
        private String extractReply(Map<?, ?> response) {
            try {
                var choices = (java.util.List<Map<String, Object>>) response.get("choices");
                var message = (Map<String, Object>) choices.get(0).get("message");
                return (String) message.get("content");
            } catch (Exception e) {
                return response.toString();
            }
        }
    }

                    .setSubject(userDetails.getUsername())

    @Service
    @RequiredArgsConstructor
    public class CourseService {
    
        private final CourseRepository courseRepository;
    
        public List<Course> findAllPublished() {
            return courseRepository.findByPublishedTrue();
        }
    
        public List<Course> findByInstructor(Long instructorId) {
            return courseRepository.findByInstructorId(instructorId);
        }
    
        public List<Course> search(String keyword) {
            return courseRepository.findByTitleContainingIgnoreCase(keyword);
        }
    
        public Course findById(Long id) {
            return courseRepository.findById(id)
                    .orElseThrow(() -> ResourceNotFoundException.of("Course", id));
        }
    
        public Course create(CourseRequest request, User instructor) {
            Course course = Course.builder()
                    .title(request.getTitle())
                    .description(request.getDescription())
                    .instructor(instructor)
                    .level(request.getLevel() != null ? request.getLevel() : "BEGINNER")
                    .published(Boolean.TRUE.equals(request.getPublished()))
                    .build();
    
            if (request.getCategoryId() != null) {
                Category category = new Category();
                category.setId(request.getCategoryId());
                course.setCategory(category);
            }
    
            return courseRepository.save(course);
        }
    
        public Course update(Long id, CourseRequest request) {
            Course course = findById(id);
            if (request.getTitle() != null) course.setTitle(request.getTitle());
            if (request.getDescription() != null) course.setDescription(request.getDescription());
            if (request.getLevel() != null) course.setLevel(request.getLevel());
            if (request.getPublished() != null) course.setPublished(request.getPublished());
            return courseRepository.save(course);
        }
    
        public void delete(Long id) {
            courseRepository.deleteById(id);
        }
    
        public Course publish(Long id) {
            Course course = findById(id);
            course.setPublished(true);
            return courseRepository.save(course);
        }
    }

    @Service

        public Enrollment enroll(User user, Course course) {
            if (enrollmentRepository.existsByUserIdAndCourseId(user.getId(), course.getId())) {
                throw new IllegalArgumentException("Already enrolled in this course");
            }
            Enrollment enrollment = Enrollment.builder()
                    .user(user)
                    .course(course)
                    .status(Enrollment.Status.ACTIVE)
                    .build();
            return enrollmentRepository.save(enrollment);
        }

            return enrollmentRepository.findByUserId(userId);
        }

            return enrollmentRepository.findByCourseId(courseId);
        }

            Enrollment enrollment = enrollmentRepository.findByUserIdAndCourseId(userId, courseId)
                    .orElseThrow(() -> new ResourceNotFoundException("Enrollment not found"));
            enrollment.setStatus(Enrollment.Status.COMPLETED);
            enrollment.setCompletedAt(LocalDateTime.now());
            return enrollmentRepository.save(enrollment);
        }

            Enrollment enrollment = enrollmentRepository.findByUserIdAndCourseId(userId, courseId)
                    .orElseThrow(() -> new ResourceNotFoundException("Enrollment not found"));
            enrollment.setStatus(Enrollment.Status.DROPPED);
            enrollmentRepository.save(enrollment);
        }
    }

    @Service
    @RequiredArgsConstructor
    public class QuizService {
    
        private final QuizRepository quizRepository;
        private final ObjectMapper objectMapper = new ObjectMapper();
    
        public Quiz findById(Long id) {
            return quizRepository.findById(id)
                    .orElseThrow(() -> ResourceNotFoundException.of("Quiz", id));
        }
    
        public List<Quiz> findByLesson(Long lessonId) {
            return quizRepository.findByLessonId(lessonId);
        }
    
        @SneakyThrows
        public Quiz create(QuizRequest request) {
            Quiz quiz = Quiz.builder()
                    .title(request.getTitle())
                    .passingScore(request.getPassingScore() != null ? request.getPassingScore() : 60)
                    .build();
    
            if (request.getLessonId() != null) {
                Lesson lesson = new Lesson();
                lesson.setId(request.getLessonId());
                quiz.setLesson(lesson);
            }
    
            List<Question> questions = new ArrayList<>();
            if (request.getQuestions() != null) {
                for (QuizRequest.QuestionItem item : request.getQuestions()) {
                    Question q = Question.builder()
                            .quiz(quiz)
                            .text(item.getText())
                            .optionsJson(objectMapper.writeValueAsString(item.getOptions()))
                            .correctIndex(item.getCorrectIndex())
                            .explanation(item.getExplanation())
                            .build();
                    questions.add(q);
                }
            }
            quiz.setQuestions(questions);
    
            return quizRepository.save(quiz);
        }
    
        /**
         * Grades a submitted attempt: answers is a list of chosen option
         * indices, in the same order as quiz.getQuestions().
         */
        public double grade(Quiz quiz, List<Integer> answers) {
            List<Question> questions = quiz.getQuestions();
            if (questions.isEmpty()) return 0.0;
    
            int correct = 0;
            for (int i = 0; i < questions.size() && i < answers.size(); i++) {
                if (questions.get(i).getCorrectIndex().equals(answers.get(i))) {
                    correct++;
                }
            }
            return (correct * 100.0) / questions.size();
        }
    }

## Architecture

The project is a layered MOOC application with four parts:

1. **React frontend** — presents login and registration, course browsing, and student, instructor, and admin pages. It sends JSON requests to the backend.
2. **Spring Boot backend** — exposes REST endpoints, applies business rules, handles authentication, and accesses the database. Its code is divided into controllers, services, repositories, entities, and security/configuration classes.
3. **MariaDB database** — stores users, courses and lessons, enrollments and progress, quizzes and attempts, certificates, and optional AI logs.
4. **AI features** — the backend’s `AIService` dispatches chatbot, recommendation, assessment, and study-plan requests to an OpenAI-compatible chat-completions API. Standalone Python scripts under `ai/` are provided for experimentation; the backend does not call them.

A typical request travels from a frontend page through an Axios service to a Spring controller, then through a service to a Spring Data repository and MariaDB. Protected requests carry a JWT in the `Authorization` header. AI requests go from `AIController` to `AIService`, which calls the configured model endpoint when an API key is present.

    /**
     * Reads the "Authorization: Bearer <token>" header on every request,
     * validates the JWT, and populates the Spring Security context so
     * downstream controllers can rely on @PreAuthorize / getPrincipal().
     */
    @Component
    @RequiredArgsConstructor
    public class JwtAuthenticationFilter extends OncePerRequestFilter {
    
        private final JwtService jwtService;
        private final UserDetailsService userDetailsService;
    
        @Override
        protected void doFilterInternal(
                @NonNull HttpServletRequest request,
                @NonNull HttpServletResponse response,
                @NonNull FilterChain filterChain
        ) throws ServletException, IOException {
    
            final String authHeader = request.getHeader(Constants.AUTH_HEADER);
    
            if (authHeader == null || !authHeader.startsWith(Constants.TOKEN_PREFIX)) {
                filterChain.doFilter(request, response);
                return;
            }
    
            final String jwt = authHeader.substring(Constants.TOKEN_PREFIX.length());
            final String userEmail = jwtService.extractUsername(jwt);
    
            if (userEmail != null && SecurityContextHolder.getContext().getAuthentication() == null) {
                UserDetails userDetails = userDetailsService.loadUserByUsername(userEmail);
    
                if (jwtService.isTokenValid(jwt, userDetails)) {
                    UsernamePasswordAuthenticationToken authToken = new UsernamePasswordAuthenticationToken(
                            userDetails, null, userDetails.getAuthorities());
                    authToken.setDetails(new WebAuthenticationDetailsSource().buildDetails(request));
                    SecurityContextHolder.getContext().setAuthentication(authToken);
                }
            }
            filterChain.doFilter(request, response);
        }
    }

    # Software Requirements Specification (SRS)
    
    ## AI-Based Integrated MOOC Platform for Online Learning and Academic Skill Development
    
    ### 1. Introduction
    
    #### 1.1 Purpose
    This document specifies the functional and non-functional requirements
    for a unified, AI-powered MOOC (Massive Open Online Course) platform
    that combines course delivery, assessment, progress tracking, and an
    intelligent learning assistant into one system.
    
    #### 1.2 Scope
    The platform supports three user roles — **Student**, **Instructor**,
    and **Admin** — and covers:
    - Course authoring and publishing
    - Enrollment and progress tracking
    - Quizzes and automated assessment
    - An AI learning assistant (chatbot, recommendations, personalization)
    - Certificates on course completion
    
    #### 1.3 Intended Audience
    Developers, project reviewers/evaluators, and academic supervisors
    assessing the platform's design and functionality.
    
    ---
    
    ### 2. Overall Description
    
    #### 2.1 User Roles
    | Role | Capabilities |
    |---|---|
    | Student | Browse/enroll in courses, complete lessons & quizzes, track progress, chat with AI assistant, earn certificates |
    | Instructor | Create/edit/publish courses, modules, lessons, and quizzes; view enrollment data |
    | Admin | Manage users and roles, oversee platform-wide content and analytics |
    
    #### 2.2 Product Perspective
    A three-tier web application: a React single-page frontend, a Spring
    Boot REST API backend, and a MariaDB (MySQL-compatible) relational database, with a
    pluggable AI service layer.
    
    ---
    
    ### 3. Functional Requirements
    
    **FR-1 Authentication** — Users register and log in; passwords are
    hashed (BCrypt) and sessions are stateless JWTs.
    
    **FR-2 Course Management** — Instructors create courses composed of
    modules and ordered lessons (text + optional video).
    
    **FR-3 Enrollment** — Students enroll in published courses; the system
    prevents duplicate enrollment and tracks status (active/completed/dropped).
    
    **FR-4 Assessment** — Instructors (or the AI assessment service) create
    quizzes with multiple-choice questions; students submit attempts and
    receive an instant score against a configurable passing threshold.
    
    **FR-5 Progress Tracking** — The system records completion percentage
    per student per course and the last lesson visited.
    
    **FR-6 AI Assistant** — Students can ask course-related questions
    (chatbot), receive course recommendations, and get an AI-generated,
    adaptive study plan.
    
    **FR-7 Certificates** — On course completion, a certificate record
    (with a unique code) is issued to the student.
    
    **FR-8 Admin Controls** — Admins can list users, change roles, and
    deactivate accounts.
    
    ---
    
    ### 4. Non-Functional Requirements
    
    - **Security**: JWT-based auth, role-based access control (`@PreAuthorize`),
      BCrypt password hashing, CORS restricted to known origins.
    - **Scalability**: Stateless backend so multiple instances can run
      behind a load balancer; AI calls are isolated behind a service layer.
    - **Maintainability**: Clear separation of controller / service /
      repository / model layers; DTOs decouple the API contract from entities.
    - **Availability**: Health check endpoint (`/actuator/health`) for
      uptime monitoring.
    - **Usability**: Responsive React UI; role-aware navigation.
    
    ---
    
    ### 5. External Interfaces
    
    - **REST API** — JSON over HTTP, documented in `docs/API.md`.
    - **AI Provider** — OpenAI-compatible `/chat/completions` endpoint,
      configurable via environment variables (see `.env.example`).
    - **Database** — MariaDB (MySQL-compatible), schema in `database/schema/`.

    # Learnspace
    
    Learnspace is a role-based online learning platform built with React, Spring Boot, and MariaDB. Learners can browse courses, enroll, and ask an AI assistant for help. Instructors can create and publish courses, while administrators manage users.
    
    ## Features
    
    - JWT-based login and registration with student, instructor, and administrator roles
    - Course catalog, enrollment tracking, instructor course management, and role-aware dashboards
    - Course modules, lessons, quizzes, and persisted quiz attempts
    - AI assistant, recommendations, assessment generation, and study-plan request types
    - Responsive web interface and Docker Compose development environment
    
    ## Technology
    
    - **Frontend:** React 18, React Router, Axios, Vite
    - **Backend:** Java 17, Spring Boot 3.3, Spring Data JPA, Spring Security, JWT
    - **Database:** MariaDB 11.4
    - **AI:** OpenAI-compatible chat completions API; optional standalone Python examples under `ai/`
    
    ## Run with Docker Compose
    
    1. Copy `.env.example` to `.env` and set `DB_PASSWORD` and `JWT_SECRET`. Add `AI_API_KEY` to enable live AI responses.
    2. Start the services:
    
       ```bash
       docker compose up --build
       ```
    
    3. Open the frontend at [http://localhost:5173](http://localhost:5173). The API is at [http://localhost:8080/api](http://localhost:8080/api); health is at `/actuator/health`.
    
    MariaDB initializes the schema on its first start. To load demo users and courses, run `bash scripts/seed_database.sh --with-sample-data` after the database is ready. The demo accounts use `Password123`: `admin@mooc.dev`, `instructor@mooc.dev`, and `student@mooc.dev`.
    
    ## Run services locally
    
    Requirements: Java 17, Maven, Node.js 20+, npm, and MariaDB. The repository does not include a Maven wrapper.
    
    1. Create the schema using `bash scripts/seed_database.sh` (set `DB_USERNAME` and `DB_PASSWORD` if needed).
    2. Start the backend: `cd backend && mvn spring-boot:run`.
    3. In another terminal, start the frontend: `cd frontend && npm install && npm run dev`.
    
    For local frontend development, Vite proxies `/api` to `http://localhost:8080`. To use a different API URL, set `VITE_API_BASE_URL`.

    public class QuizService {
    
        private final QuizRepository quizRepository;
        private final QuizAttemptRepository quizAttemptRepository;
        private final ObjectMapper objectMapper = new ObjectMapper();
    
        public Quiz findById(Long id) {
            return quizRepository.findById(id)
                    .orElseThrow(() -> ResourceNotFoundException.of("Quiz", id));
        }
    
        public List<Quiz> findByLesson(Long lessonId) {
            return quizRepository.findByLessonId(lessonId);
        }
    
        @SneakyThrows
        public Quiz create(QuizRequest request) {
            Quiz quiz = Quiz.builder()
                    .title(request.getTitle())
                    .passingScore(request.getPassingScore() != null ? request.getPassingScore() : 60)
                    .build();
    
            if (request.getLessonId() != null) {
                Lesson lesson = new Lesson();
                lesson.setId(request.getLessonId());
                quiz.setLesson(lesson);
            }
    
            List<Question> questions = new ArrayList<>();
            if (request.getQuestions() != null) {
                for (QuizRequest.QuestionItem item : request.getQuestions()) {
                    Question q = Question.builder()
                            .quiz(quiz)
                            .text(item.getText())
                            .optionsJson(objectMapper.writeValueAsString(item.getOptions()))
                            .correctIndex(item.getCorrectIndex())
                            .explanation(item.getExplanation())
                            .build();
                    questions.add(q);
                }
            }
            quiz.setQuestions(questions);
    
            return quizRepository.save(quiz);
        }
    
        /**
         * Grades a submitted attempt: answers is a list of chosen option
         * indices, in the same order as quiz.getQuestions().
         */
        public double grade(Quiz quiz, List<Integer> answers) {
            List<Question> questions = quiz.getQuestions();
            if (questions.isEmpty()) return 0.0;
    
            if (answers == null || answers.size() != questions.size()) {
                throw new IllegalArgumentException("Submit one answer for each question");
            }
    
            int correct = 0;
            for (int i = 0; i < questions.size(); i++) {
                Integer answer = answers.get(i);
                if (answer == null || answer < 0 || answer > 3) {
                    throw new IllegalArgumentException("Answer indices must be between 0 and 3");
                }
                if (questions.get(i).getCorrectIndex().equals(answer)) {
                    correct++;
                }
            }
            return (correct * 100.0) / questions.size();
        }
    
        public QuizAttempt recordAttempt(Quiz quiz, User user, List<Integer> answers) {
            double score = grade(quiz, answers);
            QuizAttempt attempt = QuizAttempt.builder()
                    .user(user)
                    .quiz(quiz)
                    .score(score)
                    .passed(score >= quiz.getPassingScore())
                    .answersJson(writeAnswers(answers))
                    .build();
            return quizAttemptRepository.save(attempt);
        }
    
        @SneakyThrows
        private String writeAnswers(List<Integer> answers) {
            return objectMapper.writeValueAsString(answers);
        }
    }

    # Learnspace

    - Responsive web interface and Docker Compose development environment

    - **Frontend:** React 18, React Router, Axios, Vite

    ## Run with Docker Compose
